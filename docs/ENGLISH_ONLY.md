# English-Only Policy

This application ships in English only.

## Requirements

- All visible UI text must be English.
- Navigation labels must be English.
- Buttons, dialogs, tooltips and notifications must be English.
- Settings must be English.
- Error messages shown to users must be English.
- Onboarding must be English.
- Application documentation must be English.
- Do not include Chinese locale files.
- Do not include Chinese translations in application resources.
- Do not expose language-selection controls for unsupported languages.

The application may consume third-party software that internally supports other languages, but the Cowork Desktop UI itself remains English-only.
